# Shraddha Gold — Frontend (React 19 + Vite)

Premier B2B Fine Gold Jewellery Manufacturing Web Application for **Shraddha Gold**.

## Design Philosophy
- **Dark Luxury Palette**: Deep Obsidian & Charcoal (`#08090b`), Champagne Gold (`#d4af37`), and Ivory Cream.
- **Typography**: Cormorant Garamond & Cinzel for luxury headings, Plus Jakarta Sans for UI.
- **B2B Industrial Focus**: Engineered for jewellery brands, retail chains, wholesalers, and international export partners.

## Public Pages & Routes
- `/`: Comprehensive landing page featuring all 12+ sections (Hero, Capabilities, Services, Products, Process Timeline, Quality & Craftsmanship, Stats, CTA, and Direct Contact).
- `/about`: Complete narrative detailing foundry history, master goldsmiths, and metallurgical standards.
- `/services`: Turnkey B2B manufacturing services with technical engineering standards.
- `/products`: 10 curated jewellery categories with purity filters (18K, 22K, 24K), MOQs, and instant RFQ modals.
- `/contact`: Direct RFQ inquiry center with client input validation and factory location details.
- `/login`: Split-screen authentication page accepting Email, Username, or Mobile Number (zero signup links).
- `/dashboard`: Protected B2B Partner Portal for authenticated clients.

## Quick Start
```bash
npm install
npm run dev
```
Runs at `http://localhost:5173`.
